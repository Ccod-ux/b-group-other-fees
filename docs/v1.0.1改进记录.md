# B组1.0.1改进记录

日期：2026年10月11日。用户要求改进名称规则和健康接口，程序版本设为1.0.1。

## 名称规则

领域层新增SummaryNames，费用新增/修改与Excel读取器共用完整名称判定，统一识别空白、全半角括号及Unicode NFC。保留六个固定工项、章节标题、完整“合计”“小计”和“税金（百分比）”名称，不以包含某个词判断，因此“合计审核费”“税金咨询费”仍可使用。

十列数字序号明细若使用保留名称，返回Excel行号、Name及NAME_RESERVED；不再将“合计”“小计”费用静默跳过。六个固定项在对应1至6序号处正常跳过，章节与非明细合计仍正常识别；税金章节不只识别9%。数字序号的可疑名称不改变当前章节归属。

读取旧数据库记录时兼容旧版保留名称，不删除或迁移数据；仍可查询、导出及删除，修改时需改成合法名称。导出再导入遇到这些旧明细会报告错误，便于人工改名，不静默漏掉。

## 健康接口

GET /api/health返回Status与Version，不再返回过时的MVP1阶段。API项目Version为1.0.1，接口读取实际API程序集版本，响应示例为{"Status":"ok","Version":"1.0.1"}。
