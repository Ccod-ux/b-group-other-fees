运行截图仅按实际操作保存；截图中保留了操作时的原中文目录名。目录改为拼音后，代码及数据库规则不变。原始考题附件未修改，也不放进公开Git仓库或提交包；复验原附件时由接收者提供题目文件。

## 直接运行

解压后在`运行程序`文件夹打开PowerShell：

```powershell
powershell -ExecutionPolicy Bypass -File .\启动服务.ps1
```

默认地址`http://localhost:5080/api/health`。需要Windows x64及.NET Framework 4.8或兼容运行时。服务初次启动创建自己的`App_Data/other-fees.sqlite`并初始化基础数据；包内不含已有演示数据库。按Ctrl+C停止，正常重启保留数据。

启动脚本可用`-Url http://localhost:5082/`换端口，`-ResetDisabled`禁用Reset。程序配置在`OtherFees.Api.exe.config`；schema.sql和seed.json在`database`中。

## 从源码构建

在`源码`文件夹打开PowerShell：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\run.ps1
```

首次构建需要联网下载便携构建SDK及还原锁定的NuGet依赖；构建SDK不改变应用的net48目标。正常启动不清空已有数据，开始一轮独立验收时按需调用Reset，它会清空所选服务的业务数据。

## 复验入口

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\test.ps1 -OriginalImportFile 'C:\实际路径\导入其他费用清单.xlsx'
powershell -ExecutionPolicy Bypass -File .\scripts\verify-clean.ps1 -File 'C:\实际路径\导入其他费用清单.xlsx'
```

`verify-clean.ps1`要求Git可用且在Git检出中运行，因为它用`git archive`导出指定提交；提交包的源码目录不含`.git`。解压后的源码可直接使用build/test/smoke脚本，或克隆仓库后使用verify-clean。测试及HTTP复验使用独立临时数据库，不应Reset用户自己的演示库。

接口示例在`源码/examples/other-fees.http`，包括CRUD、上传及下载。图像和Excel对照均可直接查看，无需视频。该提交包覆盖程序及材料交付，面试前仍需独立理解领域规则、行识别、仓储事务与汇总计算。
